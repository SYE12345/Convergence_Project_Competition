# 📌 Sleep Soundly – 센서 기반 분리형 전기매트
## 프로젝트 개요
> 프로젝트명: Sleep Soundly (온도 센서와 감압 센서를 활용한 분리형 전기매트 기획 및 구현)</br>
> 프로젝트 목적: 기존 전기매트의 안전성 및 사용 편의성 문제를 보완하고 편안한 수면 환경 제공</br>
> 프로젝트 유형 : 융합프로젝트 (5인)</br>
> 소속: 동양미래대학교 정보통신공학과</br>
> 수상: 사회맞춤형 융합프로젝트 몰입설계 경진대회 우수상
</br>

## 🛠 개발 환경 및 사용 기술
- Arduino
- 써미스터 온도 센서
- 감압 센서
- 탄소섬유 발열체
- 연결 어댑터
- PLA (제품 설계 재질)
</br>

## 📗 핵심 기능
1. 감압 센서를 활용한 사용자 감지 및 자동 전원 On/Off 기능
2. 온도 센서를 활용한 자동 온도 조절 기능
3. 매트 분리 및 결합이 가능한 구조로 사용 환경에 따른 크기 조절
4. 전자파 차단 소재를 고려한 발열 구조 설계
</br>

## 👩🏻‍💻 주요 기술 구현 내용
1. 자동 온도 조절 기능
- 온도 센서와 Arduino를 활용해 매트의 온도 측정
- 사용자의 체온에 따라 온도를 조절하는 기능 구현
- 제품 과열 방지 및 안전성 확보를 목표로 설계
2. 감압 센서를 활용한 안전 기능
- 감압 센서로 사용자의 매트 사용 여부 감지
- 일정 시간 동안 사용자가 감지되지 않으면 자동으로 전원이 꺼지도록 설계
- 외출 또는 사용하지 않는 상황에서 발생할 수 있는 화재 위험 예방을 목표로 구현
3. 전자파 문제 개선
- 일반 열선 대신 전자파 차폐에 적합한 탄소섬유 발열체를 활용하는 방향으로 설계
- 사용자의 전자파 관련 우려를 줄이는 제품 구성 제안
4. 매트 분리 및 결합 구조
- 연결 어댑터를 활용해 매트를 분리하거나 결합할 수 있는 구조 기획
- 사용 환경과 필요에 따라 매트 크기를 조절할 수 있도록 설계
</br>
